# Lobster Merge

A cozy merge-drop puzzle in a Maine lobster pound. Drop sea creatures into the holding tank; when two of the same kind touch they merge into the next one up, from krill all the way to a whale. Keep everyone below the waterline.

- 11 hand-drawn creatures: krill, shrimp, snail, clam, crab, starfish, pufferfish, lobster, octopus, seal and whale
- Chain merges for "Wicked good!" and "Finest kind!" moments
- Unlock 6 harbor themes by discovering new creatures

`index.html` is the complete game (one file, CrazyGames HTML5 SDK v3). `covers/` and `videos/` hold the store art.
